# Quick Filler

Sistema desenvolvido em Python para leitura e processamento de arquivos PDF contendo informações de cartões de ponto.

## Tecnologias utilizadas

- Python
- FastAPI
- Uvicorn
- pypdf
- PyMuPDF
- OpenPyXL
- HTML
- JavaScript

## Funcionalidades

- Upload de arquivos PDF;
- Leitura das páginas do PDF;
- Extração de informações do cartão de ponto;
- Identificação dos dias;
- Identificação dos horários;
- Exibição dos dados processados no navegador.
